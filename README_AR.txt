Matching Game v3.0 — اللعب الأونلاين 🌐🎮
=======================================

هذا التحديث مبني على ملفات Matching Game التي رفعتها أمل بتاريخ 21 نوفمبر 2026.
يحافظ على اللعب الفردي، وضد الكمبيوتر، وبطاقات 12/16/24، والأصوات بدون موسيقى خلفية.
ويضيف غرف لاعبين على جهازين مختلفين عبر Firebase Realtime Database.

ملفات GitHub (ارفعي هذه الأربعة فقط إلى جذر المستودع):
  index.html
  style.css
  script.js
  online.js   <-- ملف جديد

ملف Firebase (لا ترفعيه بدل ملفات اللعبة):
  firebase-rules.json

التركيب — بالترتيب:
1) افتحي Firebase Console > matching-game-online > Realtime Database > Rules.
2) انسخي محتويات firebase-rules.json بالكامل بدل القواعد القديمة، ثم اضغطي Publish.
   لا تستخدمي true في .read أو .write على مستوى قاعدة البيانات.
3) تأكدي أن Authentication > Sign-in method > Anonymous = Enabled.
4) افتحي مستودع GitHub: https://github.com/amalabdulaziz/matching-game
   استبدلي index.html وstyle.css وscript.js بالملفات الجديدة، وأضيفي online.js.
   تأكدي أن الملفات الأربعة في جذر المستودع (نفس مكان index.html).
5) بعد اكتمال نشر GitHub Pages افتحي:
   https://amalabdulaziz.github.io/matching-game/
6) اختاري «لعب أونلاين»، اكتبي اسمك، ثم «إنشاء غرفة».
   أرسلي رمز الغرفة ذي الست خانات إلى لاعب بجهاز آخر.
7) يختار الصديق «لعب أونلاين»، يكتب اسمه والرمز ثم «دخول الغرفة».
8) عند وجود اللاعبين متصلين، يضغط صاحب الغرفة «بدء المباراة».

قواعد اللعب:
- من يجد تطابقًا يكسب بطاقتين ويحتفظ بالدور.
- عند عدم التطابق تظهر البطاقتان لفترة قصيرة ثم ينتقل الدور.
- الفائز من لديه عدد بطاقات أكبر في نهاية المباراة، أو تعادل.
- عدد البطاقات حسب المستوى المختار قبل إنشاء الغرفة.
- يمكن لصاحب الغرفة بدء مباراة جديدة بعد نهاية المباراة.
- «مغادرة الغرفة» لصاحب الغرفة تغلقها؛ وإذا غادر اللاعب الثاني أثناء
  الانتظار تُتاح له الخانة، أما إذا انقطع أثناء اللعب فيمكنه العودة
  من نفس الجهاز بنفس الرمز إن بقي حسابه المجهول محفوظًا.

ملاحظات مهمة:
- قواعد البيانات تسمح فقط للحسابات المجهولة المسجلة بقراءة غرفة عُرف رمزها.
  الكتابة على حالة المباراة مقصورة على العضوين، لكن هذا النموذج بلا خادم
  موثوق للتحقق من جميع النقلات؛ لا يُعتمد عليه لمنع الغش نهائيًا أو
  للمنافسات بجوائز. لا تخزني بيانات شخصية أو سرية في الغرف.
- البطاقات المخفية موجودة في بيانات اللعبة، ويمكن للمستخدم التقني الاطلاع
  عليها عبر أدوات المطور. تجربة اللعب العادل تعتمد على الالتزام بقواعد اللعبة.
- الغرف غير المحذوفة قد تبقى في قاعدة البيانات؛ نظّمي تنظيفها دوريًا
  إذا اتسع استخدام اللعبة. لا توجد خدمة تنظيف خوادم تلقائية في هذا الإصدار.
- يحتاج اللعب الأونلاين اتصالًا بالإنترنت وتحميل SDK Firebase من Google.
- ملف firebaseConfig يعرّف التطبيق، وليس كلمة مرور؛ الحماية تعتمد على Rules.
- يفضّل اختبار الغرف على جهازين قبل إعلان النسخة للجمهور.

استكشاف الأخطاء:
- إذا ظهر «صلاحيات قاعدة البيانات تمنع العملية»: راجعي نشر ملف Rules كاملًا.
- إذا ظهر «فعّلي Anonymous»: راجعي Authentication > Sign-in method.
- إذا لم يفتح رمز الغرفة: تأكدي من الأحرف الستة وحالة اتصال الجهازين.
- إذا علقت صفحة GitHub قد يكون النشر لم يكتمل؛ أعيدي التحديث بعد اكتمال Actions.

هذه نسخة تجريبية محلية تم فحصها في المتصفح باستخدام محاكاة Firebase؛
لم تُختبر مباشرة مع مشروعك الحقيقي أو جهازين متصلين بالخدمة بعد.
